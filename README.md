# Turing Makinesi ile Araç Plaka Formatı Tanıyıcı

## Proje Hakkında
Bu proje, bir Turing makinesi modeli tasarlayarak belirli bir dilin (plaka formatı) tanınmasını simüle eder. Sistem, "NNLLNNN" (N: Rakam, L: Büyük Harf) formatındaki araç plakalarını analiz eder ve format kurallarına uygunluklarına göre "KABUL" veya "RED" çıktısı verir.

## Teknik Detaylar
- **Model:** Deterministik Turing Makinesi
- **Durum Kümesi:** {q0, q1, q2, q3, q4, q5, q6, q7}
- **Programlama Dili:** Python
- **Girdi:** 7 karakterli plaka dizisi

## Gereksinimler
- Python 3.x
- VS Code veya herhangi bir Python IDE
